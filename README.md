# xrwvm-fullstack_developer_capstone

## Project Name: Cars Dealership - Full Stack Web Application

### Repository: xrwvm-fullstack_developer_capstone

This is the Capstone Project for the IBM Full Stack Software Developer Professional Certificate.

## Project Description

A national car retailer web application built with:
- **Frontend**: React.js
- **Backend**: Django (Python)
- **Database**: SQLite (Django ORM) + MongoDB (reviews)
- **Sentiment Analysis**: Flask microservice
- **Dealer Details**: Node.js + Express
- **Containerization**: Docker
- **Orchestration**: Kubernetes
- **Deployment**: IBM Cloud Code Engine
- **CI/CD**: GitHub Actions

## Features

- View all car dealerships across the USA
- Filter dealers by state
- Read and submit dealer reviews
- Sentiment analysis on reviews (Positive / Negative / Neutral)
- User authentication (Register / Login / Logout)
- Admin panel for managing data
- Fully deployed to IBM Cloud Code Engine

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 18, Bootstrap 5 |
| Backend | Django 4.2, Python 3.11 |
| Microservices | Flask (Sentiment), Node.js (Dealers) |
| Database | SQLite, MongoDB |
| Deployment | Docker, Kubernetes, IBM Cloud Code Engine |
| CI/CD | GitHub Actions |
